How it works

Each agent is a small neural network that receives sensor readings (rays cast from its body) and decides whether to jump.

Every agent in the population plays the same level simultaneously. When they all die (or the timeout hits), the fittest are selected as parents — their networks are copied, crossed over, and mutated to form the next generation.

Over many generations, the population evolves strategies for jumping gaps, scaling walls, and chaining parkour moves.

Inputs to the brain

  • N ray sensors cast from the agent (down, down-right, right, up-right, up...)
  • Current vertical velocity (normalized)
  • Whether the agent is on the ground (0 or 1)

Outputs

  • Auto-run ON: 1 output — jump (sigmoid > 0.5)
  • Auto-run OFF: 3 outputs — jump, move-left, move-right

Fitness

Max horizontal distance traveled (with a tiny bonus for time alive, so an agent that survives longer ties above one that died young at the same x).

Tips

  • Crank speed to Turbo to fast-forward evolution.
  • If the population gets stuck, raise mutation rate or hit Reset.
  • Lower difficulty if early generations can't brogress at all.
  • Save the best brain when you see something cool — you can reload it later.
